Text Studio case study.

Text utility app with case conversion, encryption tools, and a reusable ads module built for a smooth free-tier experience ahead of a Play Store production release.

PSBM Labs · Live · Role: Full build, ongoing development

CategoryProductivity · Mobile
Tech stackFlutter, Hive, AES-256
StatusLive
Our roleFull build, ongoing development

The problem

Everyday text tasks — case conversion, quick encryption, format cleanup — were scattered across multiple single-purpose apps, most of them ad-heavy in ways that interrupted the actual task.

The solution

Text Studio bundles common text utilities into one Flutter app with local Hive storage for saved snippets and AES-256 encryption for anything sensitive, paired with a reusable ads module engineered so the free tier stays fast and unobtrusive rather than interruption-driven.

Key features

  • Case conversion, formatting, and text-cleanup tools in one place
  • AES-256 local encryption for sensitive notes and snippets
  • Offline-first storage using Hive, so nothing depends on a network connection
  • Reusable, non-intrusive ads module designed around free-tier retention

The result

The app is live with a smooth free-tier experience and continues to receive ongoing feature development ahead of its next production release milestone.
