## 📖 Overview

This repository contains the source code for the **PSBM Labs** website. It is designed to provide information about the organization, showcase projects, and serve as the official online presence using GitHub Pages.

- Responsive design

- Mobile-friendly layout

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/psbmlabs/psbmlabs.github.io.git
```

### Open locally

Simply open `index.html` in your browser.

Or use a local server:

```bash
python -m http.server
```

Then visit:

```
http://localhost:8000
```

## 🌐 Deployment

This project is deployed using **GitHub Pages**.

Every push to the default branch automatically updates the live website.
